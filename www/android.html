Download Android source ZIP

Includes the scanner, Android project, bundled decoder, and packaging instructions. Do not rename this ZIP to .apk.

Generate the APK

  1. Extract the ZIP. Install Android Studio, Node.js 22+, Java 21, Android SDK 36, and build tools 36.0.0.
  2. In the extracted project folder, run npm ci, then npm run android:sync.
  3. Run npm run android:open. In Android Studio, choose Build → Generate App Bundles or APKs → Generate APKs (or Build APK(s)).
  4. The output is android/app/build/outputs/apk/debug/app-debug.apk. Transfer it to your phone, allow installation from that trusted source, and grant camera access.

Without a local Android setup

Upload the extracted project to a GitHub repository, including its .github folder. Under Actions, manually run Package Android APK. After it succeeds, download the mujahid-scanner-apk artifact and extract the APK.

Debug APKs are for testing and sideloading. Public distribution requires release signing. Test camera scanning, imports, exports, offline startup, and history on an Android device before use. Web and Android data do not sync.
